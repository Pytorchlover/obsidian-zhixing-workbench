# 计时完成提醒

专注和休息结束后，工作台打开独立置顶窗口，不主动抢走键盘焦点；窗口包含任务、本轮时长、结束时间及下一步操作。

- 专注完成：开始休息 / 再专注 5 分钟 / 关闭。
- 休息结束：开始专注 / 关闭。
- 延长 5 分钟作为新的一段专注记录，已完成时段保留。
- 设置中可关闭系统提示音，并用“预览计时弹窗”检查效果；预览不更改计时或写入日记。

计时以持久化的结束时间为准，与工作台是否打开无关。恢复应用焦点、页面可见或系统唤醒时重新检查到期。未处理的完成提醒保存在插件数据中，重新加载后静音恢复。关闭提醒不自动开始下一轮。Obsidian 完全退出或电脑休眠期间无法实时弹窗，到下一次启动或唤醒时补提醒。

独立窗口通过桌面 Electron API 创建，使用 `showInactive()`、置顶及跨工作区显示；页面禁止 Node.js、外部资源和任意导航，仅接受预设操作。若当前宿主无法创建窗口，会尝试系统通知并给出错误提示。

验证：计时与保存重试去重、过期弹窗操作、休息/延长切换、后台到期检查、HTML 转义和窗口安全配置；在 macOS Obsidian 实测窗口置顶、未获得焦点、三个按钮渲染以及关闭按钮。物理睡眠唤醒和所有全屏应用组合未逐一实测。
