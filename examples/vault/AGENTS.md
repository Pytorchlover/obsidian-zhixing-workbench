# 示例知识库维护规则

- 原始资料放 raw/，只新增、不改写既有来源；知识层放 wiki/，过程材料放 projects/，模板放 templates/。
- 实际知识卡片包含 status、type、tags、created、updated、sources。外部结论保留来源，区分来源陈述、综合推断与待验证问题。
- 入库和有价值的问答先检索已有知识，优先更新概念与比较页；同步 wiki/index.md、相关 MOC 和追加式 wiki/log.md。
- 每日提炼与每周综合默认自动生成并写入知识层，无需使用者确认。未读推荐不视作学习成果。
- 日提炼写入当日日记，周综合进入 wiki/reviews，可复用结论进入领域卡片。详细流程见 [[知识沉淀工作流]]。
- 每次超过 5 个文件的修改先列计划；不擅自移动、重命名或删除已有文件。修改前保留版本，冲突时不覆盖。
- 优先使用 Obsidian CLI 检索与维护，不默认读取整个原始资料目录。

周期整理已获授权自动写入，无需逐条确认。每条内容保留来源与证据类型，自动总结不等于人工核验。写入前保存版本副本，发生编辑冲突时停止覆盖并提示。
